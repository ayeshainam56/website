# I-765 Category Confusion Explained — Which EAD Category Should You Choose? (2025 Guide)

Picking the right **eligibility category** (the little code you type in Part 2, Item 27 of Form **I-765**) is one of the cheapest mistakes an applicant can make — but it’s also one of the most painful. The wrong code can delay your EAD, lead to a denial, or break automatic-extension protections. This plain-English guide explains the most common categories, how to choose the correct one for your situation, and a step-by-step checklist so you file confidently in 2025.

> **Short answer:** Always check the **Form I-765 Instructions** first, match your situation to the USCIS eligibility list, and use the *specific* code (for example: **(c)(9)** for many adjustment-of-status applicants or **(c)(3)(B)** for post-completion OPT). Entering the wrong code is a frequent cause of denials. 

---

## Why the code matters (quick)
- USCIS uses the code you enter to determine whether you’re eligible and which evidence is required. 
- The **automatic EAD extension** rules and some employer I-9 protections rely on correct codes; a wrong code can remove those protections. 
- Some categories require specific supporting documents (SEVIS I-20 for OPT, pending I-485 receipt for adjustment applicants, TPS evidence, etc.). Providing the wrong proof = RFE or denial.

---

## Most-seen eligibility categories (and when to use them)

> **Note:** This is a *practical* list of commonly used categories. Always confirm the full, authoritative list in the Form I-765 instructions. 

- **(c)(9) — Adjustment of status applicants.**  
  Use this if you have a *pending* Form I-485 (adjustment-of-status). Many family-based and employment-based applicants file I-765 under (c)(9). 

- **(c)(8) — Asylum applicants.**  
  If you filed Form I-589 and meet the timing rules, you may apply for an EAD under (c)(8). Evidence and timing requirements differ from other categories.

- **(c)(3)(A)/(c)(3)(B)/(c)(3)(C) — F-1 students (OPT).**  
  - **(c)(3)(A)** = Pre-completion OPT (while school enrolled).  
  - **(c)(3)(B)** = Post-completion OPT (after program ends).  
  - **(c)(3)(C)** = STEM extension.  
  Student applicants must include the SEVIS/ I-20 evidence. University international offices often publish specific filing guides. 

- **(c)(5) — J-2 dependents (spouse/child of J-1).**  
  J-2s who are eligible for work authorization must use the J-2 code and include DS-2019 evidence. 

- **(c)(19) / (a)(12) etc. — TPS / Deferred Action / Special categories.**  
  TPS beneficiaries, certain deferred-action recipients, and other humanitarian categories have distinct codes. Many institutional checklists summarize these codes. 

---

## How to pick the correct code — step-by-step

1. **Read the I-765 Instructions (Part 2 guidance).** USCIS lists every eligibility category and the exact text you should enter. Start here. 
2. **Identify your legal basis to work.** Are you: adjustment applicant, asylum seeker, student on OPT, J-2, TPS beneficiary, DACA, spouse of certain visa holders, etc.? Match that to a category.  
3. **Gather required evidence for that category.** (e.g., I-485 receipt for (c)(9); SEVIS I-20 for OPT; TPS evidence for (c)(19)). USCIS’s “Checklist of Required Initial Evidence” is helpful. 
4. **If you’re renewing, use the same category that granted your prior EAD** unless your immigration status changed. (Renewing under a different code can trigger a denial.)  
5. **When in doubt, consult an adviser or attorney.** A quick check prevents denials and preserves any automatic-extension protections you might have. 

---

## Common mistakes that cause denials (and how to avoid them)

- **Entering the wrong code (or a vague one).**  
  → *Fix:* Copy the exact USCIS code text from the I-765 instructions and include the supporting document.

- **Missing category-specific evidence.**  
  → *Fix:* Use USCIS’s checklist and attach proof in front of the form (labeled).

- **Using an old form edition or outdated instructions.**  
  → *Fix:* Download the current Form I-765 and instructions directly from USCIS before filing. 

- **Changing categories on renewal without justification.**  
  → *Fix:* If you’ve changed status (e.g., from asylum applicant to adjustment applicant), include proof of the new status and explain in a short cover letter.

- **Not preserving automatic-extension protections.**  
  → To qualify for certain automatic extensions or employment-authorization protections, you must timely file and correctly identify the eligibility category. A wrong code can eliminate these safeguards.

## Quick examples (how you’d fill Item 27)

> Examples below are illustrative — always copy exact phrasing from USCIS instructions.

- Pending family-based adjustment: **(c)(9)**  
- Filed asylum application and waiting 150/180 days: **(c)(8)**  
- Applying for post-completion OPT after graduation: **(c)(3)(B)**  
- J-2 spouse seeking work authorization: **(c)(5)**

(If you’re not sure where you fit, stop and ask — a wrong entry will usually cost more time than the few minutes to confirm.)

- [ ] Latest **Form I-765** (downloaded from USCIS). 
- [ ] Exact **eligibility category** text (from Form I-765 instructions). 
- [ ] Supporting evidence for that category (I-485 receipt, SEVIS I-20, TPS docs, DS-2019, I-94, etc.). 
- [ ] Two passport-style photos (if required).  
- [ ] Filing fee or fee waiver request (if eligible) — confirm current fee on USCIS site.  
- [ ] Copy of prior EAD (for renewals) and a short cover letter explaining the category and evidence.  
- [ ] Keep photocopies of everything and track your receipt number (Form I-797C).

## FAQs (short)

**Q — Can I file online?**  
A — Yes. USCIS supports online filing for I-765 in many cases; an online filing often prompts category-specific guidance during the form flow. Always use your USCIS account. 

**Q — What if my situation fits more than one category?**  
A — File under the category that *most directly* matches your current legal basis to work and attach the strongest evidence. If you’re eligible under multiple bases, an attorney can advise whether filing under more than one category makes sense.

**Q — I filed the wrong code — can I fix it?**  
A — If you realize the mistake quickly, contact USCIS (call center) and prepare to submit a corrected application or an explanation with evidence. In some cases re-filing is required. Timely correction helps preserve automatic-extension protections. 
---

## Final tips (short & practical)

1. **Stop. Confirm. Type.** — Don’t guess Item 27; copy the exact code wording from USCIS. 
2. **Attach category proof on top.** When a reviewer opens your packet, the required evidence should be easy to find. 
3. **Preserve extensions.** If you rely on automatic EAD extension rules, timely-file and use the correct category to avoid gaps.
